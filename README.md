# 郵件簽收管理系統 v1.7.12

本版延續 v1.7.11 功能，完成全系統介面一致性、手機操作與收件人快速選取精修。

- 郵件系統使用具名 Firebase App：`mail-receipt-management`。
- Google 登入與登出只影響郵件系統，不會切換或登出發文平台帳號。
- Firestore 專案、資料庫、既有集合與 Rules 不變。
- 補印集中在「簽收單產生」的列印批次紀錄，補印不改寫首次列印資訊。
- 列印批次可重新開啟；新版批次保存列印當時的郵件資料快照。
- 收件登錄支援複製上一列、新增空白列、刪除未儲存列與近期收件人建議。
- 大宗掛號可在目前瀏覽器建立多組寄件人範本。
- 簽收單頁面只保留右上角流程提示；內容區不再重複顯示步驟文字。
- 沒有可列印郵件時顯示明確提示，並停用「產生簽收單預覽」按鈕。
- 收件登錄的複製、新增、刪除改為同列精簡按鈕，避免把資料列撐高。
- 簽收單列印範圍改為「待列印郵件／全部郵件」雙選項，並顯示當日件數；件數沿用已載入資料，不增加 Firestore 讀取。
- 郵件查詢將結果筆數與匯出移至標題右側，搜尋與篩選分為兩列，移除不規則換行與大片空白。
- 進階篩選只在展開時顯示藍色狀態；重設會同步收合進階篩選。
- 郵件登錄移除可見的備註欄，並將複製、新增、刪除統一使用系統既有按鈕樣式；既有備註資料仍完整保留於 Firestore、搜尋及匯出。
- 郵件登錄移除空白過多的快速設定卡，收件日期與「套用第一列到全部」改為同一列工具列；手機版會自然改為上下排列。
- 鍵盤操作說明縮為表格上方的輕量提示，不再搶占主要操作空間。
- 手機導覽改為可收合工具列，選擇功能後會自動收起並回到頁首。
- 手機版首頁統計改為 2×2 排列，表格支援更順暢的橫向捲動，版面邊距與卡片圓角同步縮減。
- 主要按鈕的高度、圖示、鍵盤焦點及停用狀態統一，管理清單與分頁按鈕在窄畫面更容易操作。
- 收件人欄整合近期收件人功能：保留單一輸入框，可直接輸入姓名關鍵字篩選，也可按右側箭頭展開該部門近期名單。
- 近期收件人候選由 6 位增加至最近 20 位不同姓名，只使用已載入的郵件資料，不增加 Firestore 讀取。
- 簽收單頁面改為三步驟引導式操作。

請將本資料夾內所有檔案及原始 Word、Excel 範本一起上傳，並維持目前相對路徑。
